# Language Learning Tools

## UPS Memory Palace

_A visual speech rehearsal tool that combines an editable script, colorful highlights, and images or videos to build your own memory palace._

**UPS Memory Palace** helps speakers turn visual cues into a personal guide for rehearsing speeches. It pairs an editable script with a customizable grid of up to nine images or videos.

Highlight structural signposts, key concepts, and important expressions in different colors, then review your highlighted words and phrases by color. Rehearse with your script, images, or keywords, gradually building familiarity and confidence.

You decide what each color, image, and position means. Experiment, adjust, and create a memory palace that supports your own way of remembering and speaking.
